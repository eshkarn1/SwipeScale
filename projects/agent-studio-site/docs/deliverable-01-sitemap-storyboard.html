Routing note

Route changes never remount the canvas. Navigation animates the scene from one camera state to the next while DOM content cross-fades over it — so the WebGL context, loaded geometry, and compiled shaders all survive the transition. This is the reason the canvas lives in the root layout rather than inside any page.

Budget

Text renders and is readable before the scene finishes loading, on every tier. If the 3D fails entirely, the page is still a complete, navigable, conversion-capable site — that is the acceptance test, not a nice-to-have.

05 — Before build

Open questions

None of these block style frames. All of them block the build.

Scroll length of the home page

Four pinned beats total roughly 8.6s of held scroll. That is a lot to ask before a visitor reaches the closing CTA. Options: shorten the team-graph pin, or add a persistent "Book a call" in the nav so conversion is never more than one click away at any scroll depth. Recommendation is the persistent nav CTA.

Real content for the proof strip

Logos, metrics, and testimonials are all placeholder-shaped right now. Fabricating them is not an option — the numbers need to be real before hi-fi design, because "11 hours a week" and "2 hours a week" are different designs.

Agent categories

The brief names six functions: sales, support, research, ops, content, finance. Confirm this is the final taxonomy — it drives the CMS schema, the filter UI, and the per-category 3D variant key.

Team graph — real workflows

The node graph needs at least one genuine multi-agent workflow with real hand-offs to model. An invented one will look invented.
